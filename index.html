Access levels
Walton Lift R&I has three roles
U
User (Engineer)
Logs their own tasks across categories, and can view and add to the R&I Project Manager. Views their own profile, Score, and history. No access to other people's data or admin tools.
A
Admin (Manager)
Everything a User can do, plus full visibility into the team Dashboard and Lift Search. Cannot add, approve, or remove people.
S
Superadmin
Full system access. Only Superadmins can approve pending sign-ins, assign roles, and remove people from Walton Lift R&I.
Score category weights
Superadmin only — controls how each category counts toward an engineer's Score
